# Submission Guide

## The official questions

Every candidate receives the SAME:

```text
questions/questions.json
```

You must answer those exact questions.

The organizer's private evaluation manifest is generated from the same question
file. There is no second set of questions.

## Required command

```bash
python main.py \
    --questions questions.json \
    --output submission.json
```

## Required result

Your program must produce one JSON object per official question.

A complete sample with two questions is provided in
`sample_submission.json`.

Example:

```json
{
  "question_id": "Q02",
  "payment_id": "P50001",
  "question": "What review requirement applies to P50001 and why?",
  "answer": "P50001 is above the USD 100,000 enhanced-review threshold and is destined for a high-risk jurisdiction. Enhanced and additional review are required.",
  "citations": [
    "global_payment_policy.md",
    "high_risk_jurisdictions.md"
  ],
  "facts": {
    "amount": 125000,
    "currency": "USD",
    "beneficiary_country_code": "AE"
  },
  "tools_used": [
    "get_payment",
    "search_policy"
  ]
}
```

### Required fields

- `question_id`
- `payment_id`
- `answer`
- `citations`
- `facts`
- `tools_used`

`question` is optional but recommended for traceability.

## Important

The organizer evaluator matches the candidate's `question_id` to the exact
official question.

Do not change the question or payment ID.

Do not hard-code answers such as:

```python
if question_id == "Q02":
    ...
```

The answer must be generated by your assistant.
